# Winktree – Linktree Landing Page Recreation

A responsive recreation of the Linktree landing page, built using fundamental web technologies.

## 🌐 Live Demo

[View Winktree Live](https://arnavagrawal14.github.io/Winktree/)

## 📌 About the Project

Winktree is a frontend development project that recreates the look and feel of the Linktree landing page. It focuses on clean UI design, responsive layouts, smooth animations, and interactive elements.

## 🛠️ Technologies Used

- HTML5 – Page structure and semantic elements
- CSS3 – Styling, layouts, animations, and responsiveness
- Vanilla JavaScript – Interactive components and functionality

No external frameworks or libraries are required.

## ✨ Features

- Responsive navigation bar
- Modern landing page design
- Interactive carousels
- Smooth scrolling and animations
- Hover effects and transitions
- Interactive FAQ section
- Responsive layouts for different screen sizes
