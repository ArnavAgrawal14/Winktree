# Winktree landing page clone

Plain HTML, CSS and vanilla JavaScript. No libraries, no build step.

```
Winktree-clone/
├── index.html
├── style.css
├── script.js
└── assets/images/favicon.svg
```

Run: open `index.html` in a browser (keep the files in this folder structure).
Deploy: push the folder to GitHub, then enable GitHub Pages (or drag it into Netlify/Vercel).
